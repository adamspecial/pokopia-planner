## Cloud Island: what it is, access, players, permissions, carry-over and limits

### Takeaway
A Cloud Island is a separate online save world that up to 4 players build together. It has a random layout and starts with no facilities. It has its own bag, Environment Level, shop and challenges, and it stays playable when the owner is offline. Only recipes, and probably Pokédex and recipe-list progress, carry back to the main world. Items and Pokémon never cross. Two limits differ from the main world: field crops (576 here, 511 elsewhere, from earlier research) and portal pods, which share only with other pods on the same Cloud Island.

### Cited Findings
**Access and unlock**
- [Guide] Link Play (the Pokémon Center PC menu that hosts and joins sessions and creates Cloud Islands) unlocks at Withered Wasteland Environment Level 2, after roughly 30 minutes of play. Cloud Islands also need a Nintendo Switch Online membership. One guide adds "complete the Withered Wasteland storyline and arrive at Bleak Beach" — [Game8 Cloud Island Guide](https://game8.co/games/Pokemon-Pokopia/archives/585114); [Game8 multiplayer](https://game8.co/games/Pokemon-Pokopia/archives/582101); [pokopiaguide Cloud Island](https://pokopiaguide.com/guides/cloud-island-guide) (search summaries)
- [Official] An island has an 8-character address. After entering it, the visitor is asked for the Link Code if the island uses one. The island settings include "Share with Others" (whether others may play at all) and "Display Link Code" (whether players already on the island can see the code) — [Nintendo support 71373 Cloud Island Guide](https://en-americas-support.nintendo.com/app/answers/detail/a_id/71373/~/cloud-island-guide-(pok%C3%A9mon-pokopia)); [TheGamer Cloud Islands](https://www.thegamer.com/pokemon-pokopia-cloud-island-multiplayer-complete/) (search summaries)
- [Guide] You can have only one active Cloud Island at a time. To reroll the layout you recreate the island, which deletes the old one. Backups are manual, and an island deleted without a backup is gone for good — [Game8 Can You Change Your Island Map?](https://game8.co/games/Pokemon-Pokopia/archives/584822); [TheGamer](https://www.thegamer.com/pokemon-pokopia-cloud-island-multiplayer-complete/) (search summaries)

**Size and terrain**
- [Guide] Each island is generated from a "Magic Number" seed that sets terrain shape, elevation and biome features. Sharing the number lets a friend create the same layout — [TheGamesWiki Cloud Island Guide](https://thegameswiki.com/pokopia/wiki/cloud-island-guide) (search summary)
- [Guide, single source] An island has 5 biome slots and any biome can appear in any slot. The Pokémon Center is always in the Meadowlands biome and the ruins are always in Skylands — search summary of the result set for [Game8 Cloud Island Guide](https://game8.co/games/Pokemon-Pokopia/archives/585114) / [pokopiahabitats Cloud Island](https://pokopiahabitats.com/cloud-island) (page not identified exactly)
- [Guide] "There are no facilities installed in a Cloud Island, so you will have to establish them yourself" — [Game8 Cloud Island Guide](https://game8.co/games/Pokemon-Pokopia/archives/585114) (search summary)
- Island dimensions and build-height limits: not found (see Gaps).

**Players, host and local vs online**
- [Official] Cloud Island is online play for up to 4 players at once. With no one on the island, the next player to arrive becomes host. Anyone with the address (and Link Code, if set) can play while the owner is absent — [Nintendo support 71349](https://en-americas-support.nintendo.com/app/answers/detail/a_id/71349/kw/pokopia) (search summary)
- [Guide] One guide claims a slot is always kept for the host, so only 3 can play if the host is away. Nintendo's wording above contradicts this — search summary of the result set for [Nintendo Life multiplayer guide](https://nintendolife.com/guides/pokemon-pokopia-multiplayer-guide-how-to-play-with-friends) / [VGC multiplayer](https://www.videogameschronicle.com/guide/pokemon-pokopia-multiplayer-explained/) (source not pinned)
- [Guide] There is no limit on how many people take part over time; players can take turns joining. JP blogs say the same: 4 at once, then 実質無制限 (effectively unlimited) by rotating — [dokodeyomu マルチ](https://dokodeyomu.hatenadiary.com/entry/Pokoa_Pokemon_Multiplayer); [altema クラウド島](https://altema.jp/pocoapokemon/cloudzima) (search summaries)
- [Guide] Ordinary Link Play, online or local wireless, supports up to 4 players including the host. Online uses a host-generated Link Code — [Game8 multiplayer](https://game8.co/games/Pokemon-Pokopia/archives/582101); [gamertagmythras](https://gamertagmythras.com/blog/pokemon-pokopia/pokemon-pokopia-multiplayer-guide) (search summaries)
- [Official, reported] From 2.0.1, players must run the same software version to play together, online or local — [Nintendo Life 2.0.1](https://www.nintendolife.com/news/2026/09/pokemon-pokopia-updated-to-version-2-0-1-here-are-the-full-patch-notes); [Nintendo Insider 2.0.1](https://www.nintendo-insider.com/pokemon-pokopia-update-2-0-1-patch-notes/) (search summaries)

**Who can build or take things**
- [Official] The official 2.0.0 notes name an "administrator" (JP 管理人) role. They fix a bug where "players other than the administrator may be able to place a relocation kit" (ひっこしキット) on Cloud Islands. So placing relocation kits is meant to be the administrator's job only — [Insider Gaming 2.0.0](https://insider-gaming.com/pokemon-pokopia-v2-0-0-patch-notes/); [pocoapokemon.jp Ver.2.0.0 notice](https://www.pocoapokemon.jp/ja/news/136/) (search summaries)
- [Official] 1.1.0 fixed Cloud Island bugs: item loss on host transfer, guest purchases, Vespiquen honey exchanges, repeated event messages, and jump-rope contest conditions on Cloud Island — [Game8 1.1.0](https://game8.co/games/Pokemon-Pokopia/archives/605000); [Nintendo Life 1.1.0](https://www.nintendolife.com/news/2026/06/pokemon-pokopia-updated-to-version-1-1-0-includes-improvements-and-fixes) (search summaries)
- [Guide, conflicting] Building rights: several guides say all players have equal rights to build and destroy. One guide describes per-player Builder (place/remove blocks) and Farmer (tend crops) permissions set in a Social Menu. That page reads as fragmentary, so treat it as unverified — [pokopia.center multiplayer](https://pokopia.center/posts/pokopia-multiplayer-cloud-islands-guide-2026/); [pokopiahub Cloud Islands](https://www.pokopiahub.com/guides/cloud-islands/); [gametruth](https://www.gametruth.com/guides/pokemon-pokopia-multiplayer-guide-co-op-and-cloud-island-explained/) (search summaries; which page says which was not pinned)
- [Guide] Virtual Mode makes visitors view-only. One guide warns that anyone holding the island's code can still change the island even with Virtual Mode on — [pokopiaguide Cloud Island & Virtual Mode](https://pokopiaguide.com/guides/cloud-island-guide); [TheGamer](https://www.thegamer.com/pokemon-pokopia-cloud-island-multiplayer-complete/) (search summaries)
- [Unverified, news headline] A news story reports a "griefing gang" blowing up players' endgame builds, which shows that open islands can be wrecked — [AOL](https://www.aol.com/articles/pok-mon-pokopia-griefing-gang-164604891.html) (headline only)

**What carries between a Cloud Island and the main world**
- [Guide] Each Cloud Island has its own bag: you can't bring bag items from your town to a Cloud Island or back. It has its own Environment Level and shop, independent of main-game progress. Trainer Rank doesn't rise from Cloud Island play — [Game8 Cloud Island Guide](https://game8.co/games/Pokemon-Pokopia/archives/585114); [Game Rant Cloud Islands](https://gamerant.com/pokemon-pokopia-cloud-islands-guide/) (search summaries)
- [Guide] Recipes learned or bought on a Cloud Island carry over permanently to the main save, the one exception — [pokopiahub](https://www.pokopiahub.com/guides/cloud-islands/); [Game Rant](https://gamerant.com/pokemon-pokopia-cloud-islands-guide/) (search summaries)
- [Guide] Main-game Pokémon can't be brought to a Cloud Island, and Cloud Island Pokémon can't go to the main areas. Pokédex entries earned on a Cloud Island stay on the save, but Pokémon first found there don't show as fully discovered in the main-world Pokédex — [Game Rant](https://gamerant.com/pokemon-pokopia-cloud-islands-guide/) (search summary)
- [Guide] Serebii: "all your items from the main story do not carry over and so it is starting anew, but your Pokédex and recipes lists remain" — [Serebii Cloud Islands](https://www.serebii.net/pokemonpokopia/cloudislands.shtml) (search summary)
- [Unverified] A GameFAQs thread says permanent upgrades carry over, including moves, bag expansions and PP meter size, along with recipes, stamps and habitat info — [GameFAQs thread](https://gamefaqs.gamespot.com/boards/559184-pokemon-pokopia/81129111) (search summary)
- [Unverified, conflicting JP blogs] One says items are collected into the PC BOX on return. One says only the host keeps new recipes. One says you can take one Pokémon along — [altema](https://altema.jp/pocoapokemon/cloudzima); [adoado マルチ仕様](https://adoado.hatenablog.jp/entry/2026/03/13/160521); [babblegum クラウド島とまっさらな街の違い](https://babblegum.hatenablog.com/entry/2026/07/27/104430) (search summaries; which blog says which was not pinned)

**Limits that differ from the main world**
- [Community-tested, earlier research] Field crops cap at 576 per Cloud Island against 511 per main-world area. Other per-area caps recorded earlier (generators 128, poles/transmitters 252 or 256, powered items 1,024, community boxes 32) were not reported to differ on Cloud Islands — earlier notes in this repo, [ぽこポケ学会 色々な上限](https://kyu49.github.io/Pokopia/limitation/)
- [Guide] Portal pods (きょうゆうそうち, 2.0.0) hold 80 slots. Pods placed on a Cloud Island share contents only with other pods on that Cloud Island, not with the main towns — [gamepedia Ver.2.0.0](https://gamepedia.jp/pocoapokemon/archives/5548) (search summary)
- [Guide] Cloud Island shop recipes unlock at Cloud Island Environment Level 3 and 7. Seed unlocks (earlier research, Serebii): wildflower Lv 1, bean Lv 3, tomato and wheat Lv 4, potato Lv 5 — [Game8 Cloud Island Guide](https://game8.co/games/Pokemon-Pokopia/archives/585114) (search summary); [Serebii Bean seeds](https://www.serebii.net/pokemonpokopia/items/beanseeds.shtml) (earlier notes)
- [Guide, single source] Dream Island visits are "1 (2 with Cloud Island)" a day, meaning a Cloud Island may allow one extra visit — [Rankedboost Dream Islands](https://rankedboost.com/pokopia/guides/dream-islands/) (search summary)
- [Official] 1.0.3 fixed a bug in Cloud Island creation — [Shacknews 1.0.3](https://www.shacknews.com/article/148637/pokemon-pokopia-update-1-0-3-patch-notes) (search summary)

### Inferences
- For the planner, treat a Cloud Island as its own area with its own Environment Level (1–10), its own shop unlock ladder and a 576 field-crop cap. Don't let main-world inventory feed Cloud Island builds.
- The "administrator" wording in the official 2.0.0 note suggests a permission tier exists, at least for relocation kits. Whether the owner can stop guests building is still unclear.
- Because recipes carry over, a Cloud Island shop is a second route to recipes for the main world.

### Gaps
- Island dimensions (tiles), build-height limit and whether terrain types match main-world biomes: no source found.
- Exact permission controls (who may break blocks, take from boxes or farm): sources conflict, and Nintendo 71373 could not be read.
- Whether Cloud Island Pokémon arrive through habitats as in the main world, and which Pokémon can appear there: no source found.
- Peakychu: the Kotaku link "ghost Pikachu Peakychu Cloud Island" appeared in results, but its content was not seen. A Glaze Opticals page claiming a hidden Peakychu at "Environment Level 20" looks like spam and contradicts the 1–10 scale.

## Dream Islands: the Dream Island specialty, dolls, contents, duration, rewards and resets

### Takeaway
Drifloon is the only Pokémon with the Dream Island specialty. Once it lives in its habitat, showing it a doll, or placing a doll and inspecting it, sends you to a temporary island themed on that doll: Wasteland, Ocean, Rock Peak, Volcanic, Sky, random (Ditto) or, with the DLC, Bubbly Basin (Starmie). Islands are material farms with legendary encounters. Most guides say one visit a day with a reset at 5:00, and timed events often place their currency there.

### Cited Findings
- [Official] To visit a Dream Island you must befriend Drifloon and complete its habitat, then find a doll for it. Different dolls lead to different Dream Islands — [Nintendo support 71382 How to visit a Dream Island](https://en-americas-support.nintendo.com/app/answers/detail/a_id/71382/~/how-to-visit-a-dream-island-(pok%C3%A9mon-pokopia)) (search summary)
- [Guide] Drifloon is the only Pokémon with the Dream Island specialty. You befriend it in Withered Wasteland with the "Riding Warm Updrafts" habitat, which needs 3 campfires — [Bulbapedia Dream Island (specialty)](https://bulbapedia.bulbagarden.net/wiki/Dream_Island_(specialty)); [TheGamesWiki](https://thegameswiki.com/pokopia/wiki/dream-island-specialty) (search summaries)
- [Guide] Show a doll to Drifloon, or place a doll on the ground and inspect it, and Drifloon offers the trip. One guide says each trip uses up one doll — [Nintendo Life Dream Island guide](https://www.nintendolife.com/guides/pokemon-pokopia-dream-island-guide-all-materials-dolls-and-islands); [VGC](https://www.videogameschronicle.com/guide/pokemon-pokopia-dream-island-all-dolls-and-islands-explained/) (search summaries). data.json treats a doll as a "Dream Island key", which fits a reusable key. The sources conflict on whether a doll is used up.
- [Guide] Doll to island: Eevee = Wasteland; Pikachu = Ocean; Clefairy = Rock Peak; Arcanine = Volcanic; Dragonite = Sky; Ditto = random. One guide also lists Magikarp and Gardevoir dolls that no other source mentions — [Dexerto Dream Islands](https://www.dexerto.com/wikis/pokopia/dream-islands/); [Rankedboost "All 7 Dolls"](https://rankedboost.com/pokopia/guides/dream-islands/) (search summaries)
- [Guide] Materials by island: Ocean gives twine, sea glass fragments and seashells. Rock Peak gives cave mushrooms, copper ore, limestone and ice. Wasteland gives Leppa Berries, vine rope and glowing mushrooms. Volcanic gives iron ore, gold ore and glowing stone. Sky gives wastepaper, Pokémetal fragments and crystal fragments. Every island also has stardust and furniture — [Rankedboost](https://rankedboost.com/pokopia/guides/dream-islands/); [Dexerto](https://www.dexerto.com/wikis/pokopia/dream-islands/) (search summaries)
- [Official, 1.1.0] "You can now obtain blocks of volcanic rock on Volcanic Dream Islands" — [Game8 1.1.0](https://game8.co/games/Pokemon-Pokopia/archives/605000) (search summary)
- [Guide, earlier research] Fields spawn at random on the rock-mountain and volcano Dream Islands — [GameWith bean](https://gamewith.jp/pocoapokemon/547471) (earlier notes)
- [Guide, conflicting] Legendaries: most guides list Suicune (Wasteland), Raikou (Ocean), Entei (Volcanic), Mewtwo (Sky) and none on Rock Peak. Rankedboost says Mewtwo appears at random through the Ditto doll and Raikou needs a story prerequisite — [allthings.how](https://allthings.how/pokopia-dream-islands-every-doll-island-and-legendary-pokemon/); [Rankedboost](https://rankedboost.com/pokopia/guides/dream-islands/) (search summaries)
- [Guide, conflicting] Visit limit: most say one island type per day, resetting at 5:00 AM. Rankedboost says "1 (2 with Cloud Island)". pokopiahabitats says 3 a day. One guide says the limit can be reset by changing the console clock. Revisiting the same island the same day is allowed, but materials don't respawn until the next day — [Rankedboost](https://rankedboost.com/pokopia/guides/dream-islands/); [pokopiahabitats](https://pokopiahabitats.com/guides/pokemon-pokopia-dream-island-guide); [pokopia.dev](https://pokopia.dev/dream-islands) (search summaries)
- [Guide] Bubbly Basin Dream Island (DLC): the Starmie Doll comes from Frillish's request once Bubbly Basin reaches Environment Level 3. Given to Drifloon, it leads to a Dream Island where Phione is the only Pokémon. Phione sits in a walled-off brick room and isn't guaranteed every visit. It fills Bubbly Basin Pokédex #049 — [Game8 Phione](https://game8.co/games/Pokemon-Pokopia/archives/614446); [Game8 Starmie Doll](https://game8.co/games/Pokemon-Pokopia/archives/614481); [allthings.how](https://allthings.how/pokemon-pokopia-how-to-get-phione-in-bubbly-basin-2/) (search summaries). Sources disagree on whether the doll's cave is to the north-east ([gamertw](https://pokopia.gamertw.com/guide/dream-island)) or north-west ([Sportskeeda](https://www.sportskeeda.com/pokemon/where-find-phione-pokemon-pokopia)).
- [Guide] In Bubbly Basin, Drifloon comes to you underwater — search summary, [simscommunity Bubbly Basin Dream Island](https://simscommunity.info/2026/08/11/exploring-the-pokopia-bubbly-basin-dream-island/)
- [Guide] Event currencies are farmed on Dream Islands. Cotton Spores (Hoppip event) are pulled in by holding Y. Syrupy Apples (Applin event) grow on special trees, about 40–60 per visit — [Nintendo Life Hoppip](https://www.nintendolife.com/news/2026/03/pokemon-pokopia-limited-time-special-event-announced-more-spores-for-hoppip); [Nintendo Life Applin](https://www.nintendolife.com/guides/pokemon-pokopia-apples-to-applin-event-guide) (search summaries)
- [Official] Bug history: 1.0.3 fixed Dream Island travel stranding players in Palette Town. 2.0.0 fixed being sent to a Dream Island when an online session ended. 2.0.1 fixed loading-screen hangs, and pokeos lists hangs returning from a Dream Island as a known issue — [Shacknews 1.0.3](https://www.shacknews.com/article/148637/pokemon-pokopia-update-1-0-3-patch-notes); [Insider Gaming 2.0.0](https://insider-gaming.com/pokemon-pokopia-v2-0-0-patch-notes/); [pokeos patch notes](https://www.pokeos.com/p/pokopia/patch-notes) (search summaries)

### Inferences
- A Dream Island is a daily material source, not a buildable area. The planner should model it as a per-day material yield, not a plot.
- The data.json label "Doll (Dream Island key)" fits guides that describe showing a doll. The "consumes one doll" claim comes from one guide and may be wrong.

### Gaps
- Time limit per visit, and whether anything placed on a Dream Island persists: no source found.
- Exact rules on what comes back (everything gathered, or only some): most likely everything gathered, but no source states it.
- Full doll list (7 vs 8 including Starmie), and how to get each doll: not collected here.

## Bubbly Basin: what it is, when it arrived, unlock, Pokédex, materials, items and rules

### Takeaway
Bubbly Basin (JP ブクブクうみぞこの街) is the paid Expansion Pass Part 1. It is an underwater town released alongside the free Ver. 2.0.0 (4–5 Aug 2026). You need the Expansion Pass ($34.99 for all 3 parts), the Bleak Beach request "Raise the environment level!" and the free Dive move. It has its own 50-entry Pokédex (data.json), its own Environment Level (to 10) and shop, whirlpools, buoyant blocks, watermelons, smoothies and a Dream Island with Phione.

### Cited Findings
- [Official] Expansion Pass Part 1: Bubbly Basin came out with the free ver. 2.0.0. The press release is dated 5 Aug 2026, and Nintendo Life dates 2.0.0 to 4 Aug 2026 — [TPCi press release](https://press.pokemon.com/en/releases/Pokemon-Pokopia-Expansion-PassPart-1-Bubbly-Basin-Available-Now); [Nintendo Life 2.0.0](https://www.nintendolife.com/news/2026/08/pokemon-pokopia-updated-to-version-2-0-0-here-are-the-full-patch-notes); [Famitsu](https://www.famitsu.com/article/202607/82881) (search summaries)
- [Official/Guide] The Expansion Pass costs $34.99 and covers Parts 1–3. Parts can't be bought separately — [Game8 Expansion Pass](https://game8.co/games/Pokemon-Pokopia/archives/582236); [Dexerto Expansion Pass](https://www.dexerto.com/wikis/pokopia/expansion-pass-dlc-guide/); [pokopia.pokemon.com Expansion](https://pokopia.pokemon.com/en-us/expansion/) (search summaries)
- [Official] To start Part 1, you must complete "Raise the environment level!" in Bleak Beach and learn Dive, which is in the free update. Dexerto adds knowing Surf and being able to jump (not in the official notes) — [TPCi press release](https://press.pokemon.com/en/releases/Pokemon-Pokopia-Expansion-PassPart-1-Bubbly-Basin-Available-Now); [Dexerto](https://www.dexerto.com/wikis/pokopia/expansion-pass-dlc-guide/) (search summaries)
- [Official] Pass-only content: the underwater town, its story, extra furniture and outfits, new Pokémon, the extra Dream Island, watermelons, smoothies, buoyant blocks and the "sea-floor mystery". Dive, underwater building and portal pods are free for everyone in 2.0.0 — [TPCi press release](https://press.pokemon.com/en/releases/Pokemon-Pokopia-Expansion-PassPart-1-Bubbly-Basin-Available-Now); [pokedaily](https://pokedaily.net/pokopia/expansion) (search summaries)
- [Repo data] data.json holds 50 Pokémon with dex "Basin" (308 Main, 9 Event). Phione is Basin #049 per [allthings.how](https://allthings.how/pokemon-pokopia-how-to-get-phione-in-bubbly-basin-2/) (search summary).
- [Guide] Whirlpools (2.0.0) spawn in deep ocean water, 7 to 20 tiles below the surface in Bubbly Basin. Up to 5 exist at once, and they regenerate during the day, so you can get more than 5 a day. Drops include watermelon, watermelon seeds, seabed flower seeds, star-spotted rock, Pokémetal and sea glass fragments. Some recipes come from "sparkling whirlpools" — [Serebii Whirlpools](https://www.serebii.net/pokemonpokopia/whirlpools.shtml); [Bulbapedia Rippling water](https://bulbapedia.bulbagarden.net/wiki/Rippling_water_(Pokopia)) (search summaries)
- [Guide] Bubbly Basin PC shop recipe unlocks: Environment Level 4 (pointed wooden fencing), Lv 8 (submarine door, hatch), Lv 10 (stone-accent wall). data.json shop sources run from Bubbly Basin Lv 2 to Lv 10. Buoyant block is Lv 2, watermelon seeds Lv 3 and seabed flower seeds Lv 2 (earlier research) — [Game8 Bubbly Basin recipes](https://game8.co/games/Pokemon-Pokopia/archives/582581) (search summary); [Serebii Buoyant block](https://www.serebii.net/pokemonpokopia/items/buoyantblock.shtml) (earlier notes)
- [Guide, earlier research] Underwater fields need Dive. The rototiller works on the sea floor, and watermelon, sea grapes and land crops all grow there — [Game8 水中栽培](https://game8.jp/pocoapokemon/804154) (earlier notes)
- [Official, 2.0.0] Pokémon with the Build specialty can build underwater, and Strength works underwater — [Shacknews 2.0.0](https://www.shacknews.com/article/150259/pokemon-pokopia-ver-2-0-0-patch-notes); [pokeos](https://www.pokeos.com/p/pokopia/patch-notes) (search summaries)

### Inferences
- The planner's "Bubbly Basin (Expansion Pass)" source tag is right: the area and its shop items need the paid pass, but Dive and underwater building are free. Builders without the pass can build underwater in the base areas, but have no Basin town.
- A whirlpool depth of 7–20 tiles is a usable constraint if the planner models underwater layers.

### Gaps
- The Basin's map size, its own high-ground threshold, and any caps that differ from the base areas: no source found.
- The official number in the Bubbly Basin Pokédex: data.json has 50, but no source confirmed a total.

## Palette Town and other added areas

### Takeaway
Palette Town (JP まっさらな街) is a base-game area west of Withered Wasteland, not DLC. Sources disagree on when it unlocks: early via Rock Smash, 13 bridge planks or Surf, or post-game at Master rank and Environment Level 7. It has its own habitat variants, rarities, challenges and a shop to Lv 10, and it is the only place GameShare works. Bubbly Basin is the only added town so far. Part 2 (9 Dec 2026) is mainly accessories, and reports differ on whether it adds new towns.

### Cited Findings
- [Guide, conflicting] Palette Town unlock: (a) early access, a sandbox west of Withered Wasteland once Hitmonchan teaches Rock Smash, crossed with at least 13 bridge planks or later with Surf, credits not required — [pokopia.center Palette Town](https://pokopia.center/posts/pokopia-palette-town-guide-unlock-2026/). (b) post-game, after the main story and Master rank, Environment Level 7 — [pokopiahub area unlock](https://www.pokopiahub.com/guides/area-unlock-guide/); [Fextralife Palette Town](https://www.wiki.fextralife.com/all-pallet-town-exclusive-pokemon-in-pokopia/). (c) "Available immediately" — [Dexerto islands](https://www.dexerto.com/wikis/pokopia/islands/) (search summaries)

## Online features: visiting, sharing builds, trading, NSO, GameChat, amiibo, HOME

### Takeaway
Online play (Link Play over the internet, Cloud Islands, remote GameShare via GameChat) needs Nintendo Switch Online and a Nintendo Account. Local wireless and nearby GameShare don't. You visit other islands in view-only "Virtual Mode" with the Mysterious Goggles (100 Life Coins, Env Lv 3) and an island code. The camera and 3D printer let you copy and print objects you see, which is how builds are shared; no blueprint-file sharing was found. No trading between players, Pokémon HOME link or amiibo support was found.
